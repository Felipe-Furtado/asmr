# ASMR — A Simple Markdown Reader

A lightweight, native macOS app for reading Markdown files the way they were meant to be read.

## The Problem

Markdown is everywhere. READMEs, specs, API docs, SOPs, personal notes — plain `.md` files are now a de facto standard for interoperable text documents. But macOS has no native way to open them beautifully:

- **TextEdit** renders raw syntax, not formatted output
- **Word** mangles the formatting
- **VS Code / Xcode** are full IDEs — overkill for just reading a document
- **Browser extensions** require extra steps and don't integrate with Finder

There's no "Preview for Markdown" on macOS. ASMR is that app.

## What It Is

ASMR is a minimal, read-focused macOS app that opens `.md` files and renders them as clean, readable documents — just like Preview does for PDFs and images. No editing required. No subscription. No electron bloat.

- Opens `.md` files directly from Finder (double-click or `open` in Terminal)
- Renders standard Markdown: headings, bold, italics, lists, code blocks, tables, links
- Respects the system light/dark mode
- Stays out of the way

## What It Is Not

- Not an editor (that's what your IDE is for)
- Not a note-taking app
- Not a sync service
